# Business Analytics — Customer Insights

## Project Overview

This project explores online retail transaction data to understand revenue performance, customer purchasing behaviour, customer value, and potential customer inactivity.

The goal is to turn transaction data into actionable business insights using SQL, Python, and Power BI.

## Objectives

- Validate and clean the transaction dataset.
- Analyse sales, quantities, customers, and purchasing patterns.
- Develop customer-level metrics using RFM analysis (Recency, Frequency, Monetary Value).
- Define and calculate relevant business KPIs.
- Build an interactive Power BI dashboard.
- Present evidence-based findings and practical recommendations.

## Tools and Technologies

- **MySQL:** Data validation, querying, and transformation.
- **Python:** Pandas-based cleaning, exploratory data analysis, and customer segmentation.
- **Power BI:** KPI reporting and interactive visualisation.

## Project Roadmap

1. Business problem framing
2. Data cleaning and exploratory data analysis
3. KPI development and customer analysis
4. Dashboard development
5. Final case study and recommendations

## Dataset

The project uses an online retail transaction dataset. Data-quality issues, exclusions, assumptions, and analytical limitations will be documented during the analysis.
